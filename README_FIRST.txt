WORDWISE - START HERE

1. Extract the WordWise folder from the ZIP file.
2. Open the extracted WordWise folder.
3. Double-click RUN_WORDWISE.bat.
4. Wait for the terminal to show that the server is running.
5. Open http://127.0.0.1:5000 in Chrome if it does not open automatically.
6. To stop the app, click the terminal window and press Ctrl+C.

IMPORTANT:
- You need Python installed on Windows.
- The first run needs an internet connection to install Flask.
- If Windows says Python cannot be found, install Python from https://www.python.org/downloads/
  and tick "Add python.exe to PATH" during installation.
